## ✨ v0.8.0–v0.8.6 最新旗舰特性

- **极薄 `app.asar` 主进程引导层 × SSE 实时热引擎（免 `19222` 端口 + 原生 Swarm 更新自愈，#12）**：
  - 支持在「精细工坊 → ⚡ 5. 原生 0ms 沉浸引导」或关闭 Antigravity 后执行 `node bin/gemineko-hive.mjs host-asar apply`：仅向 `dist/main.js` 增量写入 ~4KB 独立标记块（不修改 `dist/preload.js`、绝不覆写 `app.asar.bak`，与 `chinese-toolkit` / `agy-meme` 安全共存、随时 `host-asar restore` 无损剥离）；
  - 实现深色主题 `0ms` 防白屏、自动发现 Sidecar `runtime-endpoint.json` 并通过 `/api/host-events` SSE 毫秒级推送配色/主题/汉化与重播事件，同时自动解锁 Chromium 冷启免手势播音，**彻底告别 `--remote-debugging-port=19222` 参数依赖**（并继续保留 CDP 作为免改包兜底通道）；
  - Sidecar 启动时自动检测并自愈被客户端更新覆盖的原生 Swarm 面板补丁，确保更新后不掉皮肤。
- **「星钻 × 五哈基米」60fps 剧场级反重力启动动画（#11）**：
  - 每次冷启经过就绪门禁与首帧预解码后自动演绎约 `2.6s` 实时光学片头：反重力星尘升腾 → 1024px 3D 棱镜星钻绽放 → 5 位真实动态 APNG 哈基米沿星轨依次亮起环绕 → 炫彩品牌字标，自动随当前主题深浅色与角色强调色联动；
  - **智能双轨无缝收尾**：落在首页时片头星钻精准飞入融合到首页大星钻 Logo；落在历史对话页时化作反重力棱镜光浪向上浮散退场；任意点击 / `Esc` 瞬时跳过，严格遵守「专注 0fps」「关闭动效」与全局静音开关；
  - **开机声音仪式感**：内置立体声星晶反重力主旋律音效（`startup-chime.mp3`）与猫娘招牌开机问候语音（`startup-welcome.mp3`），可在「精细工坊 → 6. 反重力启动动画」独立开关音效/语音或随时点击 **✨ 立即重播预览**（主窗口快切栏亦提供一键重播）。
- **12 控件专属「哈基米热梗」彩蛋与软萌配音（#6, #7）**：
  - 主窗口 9 大控件 + 侧边栏 3 大控件均配备专属互动彩蛋（输入栏小猫连击变身脊背龙哈气、右键叮咚鸡运势盲盒、侧边栏凌晨三点跑酷、投喂小鱼干全窝围观、工坊炼丹试妆等），集齐 `12/12` 解锁终极「至尊圆头耄耋·星河大阅兵」，内置 `Qwen3-TTS-12Hz-1.7B-VoiceDesign` 定制全套软萌猫娘语音并经 Sidecar `/gemineko-audio/` 零占主包体播放。

## 📦 安装方式（30 秒上手）

### 方式一：通过 AGY Market（推荐，零命令行）
打开 **AGY Market** 侧边栏 → 点击右上角 **「链接添加」** → 粘贴下方仓库地址安装即可：
```text
https://github.com/AEmbers/gemineko-hive
```

### 方式二：手动克隆部署

**Windows（PowerShell）：**
```powershell
git clone https://github.com/AEmbers/gemineko-hive.git
powershell -ExecutionPolicy Bypass -File .\gemineko-hive\scripts\install-local.ps1
```

**macOS / Linux：**
```bash
git clone https://github.com/AEmbers/gemineko-hive.git ~/.gemini/config/plugins/gemineko-hive
```

   - 主窗口支持 **新版 3 视觉模式**（默认 **`optical-neko` 光学高定哈基米** / **`vivid` 浓郁二次元** / **`minimal` 极简专注**）、`ask_question` 提问抱臂仰头思考 + `A? B? C? D?` 轮盘舞台、**全链路猫娘表情包渲染与收工贴纸**、`Overview` 悬浮卡猫耳重绘、发光 SVG 爪印雨（`Ctrl+Shift+P`），以及 **面向中文与国际用户的可选 Antigravity 全量汉化**。
2. **CLI 命令行控制（可选）**：
   ```bash
   node bin/gemineko-hive.mjs status             # 检查原生 Swarm 换肤状态、精灵数与 logo 替换状态
   node bin/gemineko-hive.mjs apply              # 套用/升级后重新应用《基米窝》皮肤与入口图标
   node bin/gemineko-hive.mjs restore            # 字节级无损还原官方原版 Swarm 与小蜜蜂图标
   node bin/gemineko-hive.mjs host-asar status   # 检查原生 0ms 引导钩子及第三方补丁共存状态
   node bin/gemineko-hive.mjs host-asar apply    # 写入极薄 app.asar 主进程引导钩子（免 19222 端口）
   node bin/gemineko-hive.mjs host-asar restore  # 无损剥离原生引导钩子（保留汉化与表情包补丁）
   ```
