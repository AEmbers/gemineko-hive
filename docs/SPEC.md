# Gemineko Hive · 基米窝 — 产品需求契约 (SPEC)

> 本规格由 `/grill-me` 7 轮交互对齐后锁定，用于约束 `gemineko-hive` 的产品边界与交互验收。

## 1. 形态与双模式架构
- **双模式合一**：
  1. **原生 Swarm 无损换肤补丁**：向官方内置 `swarm/sidecars/swarm_board` 注入单文件 `gemineko-hive.js` 与标记块（`GEMINEKO_HIVE_START` / `GEMINEKO_HIVE_END`），零修改 `app.js` / `hive.js` / `gif.js` / `styles.css`，支持幂等重打与逐字节还原。
  2. **独立《基米窝》Sidecar 面板**：在 `sidecars/hive_board/` 提供只读副面板，复用同一套皮肤核心引擎；无论用户从原生 Swarm 还是独立侧边栏打开，体验完全一致。
- **面板内一键开关 + CLI 双支持**：独立《基米窝》侧边栏顶部提供「原生 Swarm 换肤」状态胶囊，可直接查看、套用、更新后恢复或还原官方原版；同时提供 `bin/gemineko-hive.mjs` 供命令行与 Agent 调用。

## 2. 角色映射双模式
- **AI 娘宇宙（默认，`ai-girls`）**：按成员名称、角色与底层模型（`/api/swarm` 中的 `model` 与 `role`）自动映射：
  - `coordinator` → 戴金色皇冠的领队 Gemini 猫娘（`neko-queen`）；
  - `claude` 系 → Claude 橙发大小姐（`claude-working`）；
  - `gpt` / `codex` / `o1` / `o3` / `sol` 系 → GPT 银发翡翠小龙娘（`gpt-working`）；
  - 其余 / Gemini 系 → 标准 Gemini 蓝紫异瞳猫娘（工作态 `gemini-working` / 休眠打盹 `gemini-sleep`）；同模型多 worker 用各自差异化色相外圈区分。
- **全员彩色哈基米猫窝（`all-hachimi`）**：不区分模型，全员展示为按成员名哈希染色的萌系哈基米猫娘，协调者戴皇冠。

## 3. 双美术包切换
- **高清 Q 版立绘（默认，`chibi`）**：基于内联 128×128 PNG Q 版立绘，配合 CSS 状态动画（工作中 Q 弹跳动发光、等待轻呼吸、休眠切打盹闭眼飘动态 `Zzz`、需确认惊叹星标闪烁）。
- **复古 32×32 像素精灵（`pixel`）**：内置纯 Canvas 32×32 高精像素绘制引擎，支持 2 帧抖耳/挥爪/皇冠/闭眼睡眠与全员色彩映射。

## 4. 界面主题与文案
- **轻盈「星空猫窝」主题（默认，`starry-hive`）**：自适应浅色与深色模式，为六边形蜂巢格添加柔光与淡淡猫爪印、为连线叠加星芒脉冲、注入紧凑可折叠顶部控制条；支持一键切回 **仅换头像极简模式（`avatar-only`）**。
- **三语文案实时切换**：`萌系中文 (neko-zh)` / `正常中文 (zh)` / `EN (en)`。

## 5. 互动彩蛋、GIF 导出与 Demo 体验
- **“捅一捅基米窝”炸毛彩蛋**：工具栏「捅一捅」按钮点击后触发蜂巢轻微震动、全员集体炸毛晃动、随机爆出萌系吐槽气泡（如“坏了，捅了基米窝了喵！”“别戳啦代码要溢出了！”）。
- **单点摸头互动**：点击面板中的小猫娘头像/气泡可冒泡回应“喵呜～干劲 +100%！”等台词。
- **GIF 导出同步**：重写 `SwarmHive.beeSrc(name)` 与 Canvas 代理，保证原生「Export GIF」导出关系图回放时同步渲染猫娘头像。
- **可选音效**：默认静音（`sound: false`），开启后用 Web Audio 合成轻柔“喵呜/叮”交互音效。
- **空状态「一键体验模拟基米窝（Demo）」**：当前对话尚未运行 `/swarm` 时，空状态注入一键体验按钮，点击即展示 5 只 AI 娘完整协作数据并解锁全部面板、画风切换与捅窝彩蛋。
