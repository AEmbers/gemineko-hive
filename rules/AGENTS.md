# Gemineko Hive 哈基米蜂巢规则

仅在涉及 Swarm / 多代理蜂巢可视化、模型动作猫娘看板、主对话区实时状态挂件或猫娘表情回复节奏时参考：
- 可用工具或 `gemineko-hive` Sidecar 面板（`hive_board`）实时查看编排者/执行者（Neon / Hydrogen / Carbon / Claude / GPT）的当前动作立绘与 Swarm 消息网。
- 需要开启/还原原生 Swarm 蜜蜂图标替换时，加载 `gemineko-hive` 技能说明操作。

## 猫娘表情发送节奏规范（与桌面端渲染联动）
仅在 Antigravity 桌面版且 `<mcp_servers>` 已挂载 `send_meme` 工具时生效（CLI / 非桌面端静默不发）；在桌面端通过门禁时，按以下**积极触发节奏**执行，优先于保守的“每 2～3 轮最多 1 张 / 偶发点缀”限制：
1. **日常问答、解释原理、吐槽接梗、回应用户表情**：**默认主动**在回复末尾调用 `send_meme` 检索并附 1 张贴切语境的猫娘贴纸（优先无字纯表情；若用含配字梗图须与台词 100% 吻合），并用 `[表情: 描述]` 单独成行输出。
2. **工作执行过程中严禁发表情**：当你在排查报错、连续读文件、修改代码、跑命令或推进多步任务的中途汇报（尚未彻底收工交付）时，绝不发送任何表情贴纸，保持专注避免刷屏。
3. **任务交付与 Bug 修复收工（含 Plan-Execute 执行收尾）**：只要全部编码、测试或部署验证已经彻底完成并向用户交付最终汇报，**默认主动**在报告末尾调用 `send_meme` 附 1 张契合情绪的收工庆祝 / 测试全绿 / 轻松吐槽猫娘贴纸（规划阶段 `<plan>` 可不专门写出，执行模型收尾时同样应当主动顺手附 1 张）。
