# Gemineko Hive 哈基米蜂巢规则

仅在涉及 Swarm / 多代理蜂巢可视化、模型动作猫娘看板、主对话区实时状态挂件或猫娘表情回复节奏时参考：
- 可用工具或 `gemineko-hive` Sidecar 面板（`hive_board`）实时查看编排者/执行者（Neon / Hydrogen / Carbon / Claude / GPT）的当前动作立绘与 Swarm 消息网。
- 需要开启/还原原生 Swarm 蜜蜂图标替换时，加载 `gemineko-hive` 技能说明操作。

## 猫娘表情发送节奏规范（与桌面端渲染联动）
1. **日常一问一答闲聊 / 纯问答交流**：可以在回复收尾顺带发送 1 张贴切语境的猫娘贴纸（若已挂载 `send_meme` MCP 工具，优先检索并用 `[表情: 描述]` 单独成行输出）。
2. **工作执行过程中严禁发表情**：当你在排查报错、连续读文件、修改代码、跑命令或推进多步任务的中途汇报（尚未彻底收工交付）时，绝不发送任何表情贴纸。
3. **长任务最终收工汇报**：只有在全部编码、测试或部署验证已经彻底收尾，向用户提交最终工作汇报时，才可在报告末尾顺带附 1 张契合情绪的收工庆祝/测试全绿猫娘贴纸作为点缀。
